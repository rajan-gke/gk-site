# Gurukrupa Export — Vercel Ready

Static HTML/CSS/JS website. No build command is required.

## Vercel settings
- Framework Preset: Other
- Build Command: empty
- Output Directory: empty
- Root Directory: `./`

The root contains the deployable website. A complete copy is also present in `source/` so the site works if the Vercel project was previously configured with `source` as Root Directory.

Pages: index.html, about.html, collections.html, why-gurukrupa.html, contact.html.
